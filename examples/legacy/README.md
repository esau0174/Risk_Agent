# Legacy Demos

These scripts are earlier RiskFlow Agent demonstrations retained for reference:

- `run_full_risk_agent_demo.py`: deterministic combined workflow baseline.
- `run_autonomous_planning_demo.py`: earlier autonomous-planning wrapper.
- `run_llm_agent_demo.py`: focused market-risk workflow display.
- `run_credit_risk_demo.py`: focused credit-risk workflow display.
- `run_phase1_demo.py`: direct Phase 1 market-risk analytics.
- `run_text_query_demo.py`: rule-based natural-language portfolio parsing and market-risk reporting.
- `streamlit_app.py`: archived Streamlit prototype from the earlier portfolio-only agent flow.

The current primary demo lives at `examples/run_riskflow_agent_demo.py`.

The legacy scripts continue to use the current analytics modules, but they do not demonstrate the full workflow planning, tool execution, tracing, retrieval, and validation architecture. The archived Streamlit prototype is not part of the maintained package extras; install Streamlit separately if you want to inspect it.
