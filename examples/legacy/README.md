# Legacy Demos

These scripts are earlier FinRisk Agent demonstrations retained for reference:

- `run_phase1_demo.py`: direct Phase 1 market-risk analytics.
- `run_text_query_demo.py`: rule-based natural-language portfolio parsing and market-risk reporting.

The current presentation-oriented demos live directly under `examples/`:

- `run_full_risk_agent_demo.py`
- `run_llm_agent_demo.py`
- `run_credit_risk_demo.py`

The legacy scripts continue to use the current analytics modules, but they do not demonstrate the full workflow planning, tool execution, tracing, retrieval, and validation architecture.
