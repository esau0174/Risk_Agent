# Expected Shortfall

Expected Shortfall estimates the average loss in the tail beyond the VaR threshold.
For a 95% confidence level, it averages returns at or below the 5th percentile threshold.
In this project, Expected Shortfall is reported as a positive loss magnitude.

Expected Shortfall provides more information about severe downside outcomes than VaR alone,
but it is still based on the historical sample used in the calculation.
